# Availability Coverage Inventory

This inventory maps availability rule shapes used in the paper to checked
artifact evidence. `availability_evidence` entries are pattern specs run by the
new inspection/diagnostic CTest target. `e2e` entries are existing compile/run
tests that continue to run through the `e2e` CTest target.

| Rule shape | Evidence | Notes |
| --- | --- | --- |
| CT literal and pure primitive folding | `availability_evidence/tyir/availability_validation.patterns`; `availability_evidence/tyir/runtime_block_partial_normalization.patterns`; `test/e2e/pass/basic/arithmetic.cst` | Checks folded literals, primitive arithmetic, and folded pure expressions inside runtime contexts. |
| Ordinary helper call folding | `availability_evidence/tyir/availability_validation.patterns`; `test/e2e/pass/runtime/availability_validation.cst`; `compiler/cstc_tyir_interp/tests/folding.cpp` | Checks CT-eligible helper calls fold when const evaluation succeeds. |
| Ordinary helper call lifting by RT actual | `availability_evidence/tyir/availability_validation.patterns`; `test/e2e/pass/runtime/plain_call_lifting.cst`; `test/e2e/pass/runtime/plain_generic_call_lifting.cst` | Checks helper calls become runtime-qualified when an actual argument is runtime-qualified. |
| Conservative ignored-argument lifting | `availability_evidence/tyir/symbolic_function_availability.patterns`; `test/e2e/pass/runtime/plain_call_lifting.cst` | Checks `first(a,b){a}` keeps `result=(param0 \| param1)` and `first(1, source())` is runtime-qualified. |
| Runtime-result declaration barriers | `availability_evidence/tyir/runtime_authority_boundaries.patterns`; `test/e2e/pass/runtime/runtime_result_function.cst`; `test/e2e/pass/runtime/runtime_authority_boundaries.cst` | Checks explicit runtime-result declarations are accepted and carry source-boundary authority, exactly like the `runtime fn` spelling. |
